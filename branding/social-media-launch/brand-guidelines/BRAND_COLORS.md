# Brand Colors

Source of truth: frontend/apps/landing/PRODUCT.md and the live landing page at https://pos.rakmyat.online/en#product. The current marketing interface uses a light theme.

| Token | HEX | Use |
|---|---|---|
| Primary violet | #6D28D9 | Logo route, key emphasis, selected actions |
| Deep violet | #4C1D95 | Dark-surface contrast and secondary emphasis |
| Secondary purple | #8B5CF6 | Nodes and restrained highlights |
| Soft lavender | #C4B5FD | Secondary shapes and light illustration details |
| Paper | #F7F5FF | Main background |
| Surface | #F0ECF8 | Raised cards and preview panels |
| White | #FFFFFF | Card interiors and reversed marks |
| Dark ink | #171327 | Main text and dark thumbnail field |
| Soft ink | #373147 | Secondary dark text |
| Muted text | #575066 | Supporting copy |
| Rules | #D9D1EB | Dividers and thin outlines |
| Success | #17643B | Status only |
| Warning | #8A5100 | Status only |
| Danger | #A3233D | Error/status only |
| Focus | #6D28D9 | Focus indicator |

The print and single-color logo variants use solid black or white only where required. They preserve the mark geometry and do not redefine the product palette.

## Contrast and use

- Use #171327 or #575066 for text on #F7F5FF or white.
- Use white text on #6D28D9 for large logo text and short action labels.
- Keep lavender as a fill, line, or large decorative accent rather than small body text.
- Pair status colors with text or a symbol; never rely on color alone.
- Dark placements use #171327 with lavender/white marks. The app itself currently forces a light theme; this does not add a dark application theme.
