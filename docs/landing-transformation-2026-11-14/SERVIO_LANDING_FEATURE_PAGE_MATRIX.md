# Dedicated page matrix

Every path has English and Arabic copy and route-specific metadata.

| Route | Purpose | Product evidence | Scope boundary |
|---|---|---|---|
| /features | Discover supported areas | Links to seven task-specific pages | No universal completion claim |
| /features/pos | Select products and send a confirmed order | Synthetic cashier capture | No offline, terminal or tax accuracy claim |
| /features/kitchen-display | Receive, bump and recall kitchen tickets | Actual ticket | Completion is separate from payment/delivery |
| /features/online-ordering | Browse and submit a cash order | Checkout and confirmation | Staff confirmation precedes kitchen preparation |
| /features/website-builder | Save and preview theme configuration | Theme editor | No instant DNS/TLS publishing promise |
| /features/inventory | Explain quantity lifecycle | Inventory capture and verified fixture | Refunds and physical returns are separate |
| /features/hr | Employee, attendance and leave records | Populated leave screen | No comprehensive payroll/accounting promise |
| /features/analytics | Operational overview | Fresh synthetic workspace | No complete financial statement claim |
| /how-it-works | Explain handoffs and setup | Verified workflow narrative | Provisioning and paid activation are separate |
| /pricing | Compare billing frequencies | Owner-approved commercial policy | Checkout unavailable; selection authorizes no charge |
| /demo | Immediate product walkthrough | Seven authentic screens | Not an interactive restaurant account |
| /contact | Demonstration options | Links to walkthrough and trial | No fictional calendar booking or lead submission |
| /privacy | Describe implemented data handling | Local event bridge and account creation | No invented legal/retention promises |

The feature template shares navigation and layout, while every feature supplies its own headline, task sequence, capture, and explicit boundary. Unknown feature slugs return 404.

## Verification

Every listed route passed the successful candidate EN/AR HTTP, server language, heading, canonical, unique-description, hreflang, structured-data and axe checks. The verified candidate covers every route at all six requested viewport widths; final protected CI repeats this and adds focus visibility/contrast checks. The `/pricing` page adds trial timing, annual calculation, same-subscription explanation and payment/activation boundaries beyond the homepage offer.
