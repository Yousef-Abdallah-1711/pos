1. **Establish a versioned fixture.** Start an isolated test database and application stack, verify the host and tenant before any writes, and seed synthetic restaurant, staff, menu, inventory and order states through supported flows. Define explicit permissions and use no customer data or production cookies. Label or mask any synthetic identity and order identifiers consistently.
2. **Record source and environment.** For each image, record app, URL/route, source commit, fixture version, capture date, locale, direction, resolved theme, viewport, device scale, browser, natural dimensions, encoding, byte size, masking and whether any transaction was submitted. Verify the app is in the intended state before capture; never substitute illustrative mockups for a claim of an actual screen.
3. **Build a 7 × 2 × 2 source matrix.** Use the existing names `dashboard`, `pos`, `kitchen`, `inventory`, `staff`, `theme`, and `checkout`; capture English and Arabic in each supported light/dark state. Existing `CaptureMedia.tsx` resolves `matrix/{name}-{locale}-{theme}.png` and the manifest tracks variants. If a locale/theme or product state is unavailable, record it explicitly and provide an honest fallback rather than inventing an image.
4. **Add purpose-built states.** Capture real synthetic POS empty and populated cart states, kitchen queue states, and any relevant dashboard components only after the product renders them. Ensure state captions and animation overlays explain what is illustrative; do not submit real orders or imply payment, automatic routing, or delivery behavior that has not been verified. Build mobile/component crops only where justified and link each crop back to its original full capture.
5. **Preserve geometry and scope.** Registry baseline dimensions are 1440×900 for desktop screens and 390×2124 for the current checkout; Arabic checkout currently uses a 2100-pixel height override. Check actual intrinsic files rather than assuming every capture matches. The checkout and website-theme images belong to the independently branded storefront; re-evaluate them based on the approved site scope rather than recoloring them automatically.
