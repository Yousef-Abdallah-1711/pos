## Method and honest limits

- Page list = every `page.tsx|page.ts|route.ts` under `frontend/apps/{dashboard,landing,super-admin}/src/app` and `frontend/apps/restaurant-website/app` (119 entries; layouts listed separately). 
- Endpoints = string literals that match a registered backend route in `08-api-inventory.csv` (verified match). Method shown as `?` where the call style could not be inferred. Endpoints reached only through dynamic string building are UNVERIFIED/missed.
- Shared permission hook calls (`/rbac/me/permissions`, `/rbac/check-permission`, `/rbac/*`, `/auth/*`) are omitted from per-page lists (every dashboard page pulls them via `useUserPermissions`); they appear only on RBAC/settings pages.
- "Unmatched" = a literal that looks like an API path but matches no registered route (possible missing backend route or a Next.js path).
- Locale: dashboard/landing/restaurant-website routes sit under `/[locale]` (en|ar). No Next route handlers exist in dashboard/landing; restaurant-website has `/api/metrics`; super-admin has `favicon.ico/route.ts`.
