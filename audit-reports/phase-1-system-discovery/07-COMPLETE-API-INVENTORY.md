## Flag legend (each maps to a finding in 03-BACKEND-ARCHITECTURE.md)

- `RBAC-NOT-ENFORCED(BE-002)`: wrapped by `wrapWithPermission(module, level)` / KDS wrapper, but no code reads the stored module/level.
- `NO-ADMIN-CHECK(BE-003)`: RBAC-administration write route; any authenticated user of the tenant may call it.
- `NO-RBAC(BE-004)`: sensitive mutation protected only by login.
- `PUBLIC+HEADER-TENANT(BE-006)`: unauthenticated; tenant+restaurant taken from request headers.
- `NO-TENANT-STATUS(BE-008)`: subscription/suspension is not checked.
- `STUB(db==nil)(BE-015)`: fake in-memory handler registered when DB connection failed at boot.
- Other flags map to the BE-id in parentheses.

## Endpoints that deserve attention (sensitive, public, or header-scoped)

| Endpoint | Why |
|---|---|
| every route behind `AuthMiddleware` | `X-Impersonation-Token: <any non-empty>` skips JWT validation (BE-001, middleware/auth.go:18-31). |
| `POST /api/v1/webhook/paymob` | Public by design. HMAC check is `return true` in `MockPaymobClient.VerifyHMAC` (service/paymob_client_mock.go:51-54); mock client is selected whenever `PAYMOB_MODE` is not exactly `live` (main.go:197-210). `docker-compose.prod.yml:74` defaults it to empty. |
| `GET/DELETE /api/v1/public/orders/{id}`, `/number/{n}/lookup`, `/{id}/status`, `/{id}/track` | Unauthenticated; tenant/restaurant from client headers; sequential integer ids; full order (customer name/phone/address) returned; DELETE cancels. |
| `POST /api/v1/public/orders` | Unauthenticated; client-selected `order_source`; `pos` triggers auto-confirm into KDS (order_usecase.go:217-229). |
| `POST /api/v1/translations/{language}/upload` | Unauthenticated write to a process-global map served to every tenant. |
| `/api/v1/impersonation/{validate,end,check}` | Public; accept token in query string. |
| `/api/v1/rbac/*` (write routes) | JWT only; no admin/owner check; any tenant user can grant permissions or roles. |
| `POST/PUT/DELETE /api/v1/users` | login only; no RBAC; can create/delete any user in the tenant. |
| `GET /api/v1/health`, `/health/ready`, `/health/metrics` | Public; health returns raw DB error text (main.go:524,543); metrics exposes `observability.Snapshot()` (main.go:551). |
| `/api/v1/public/test-routing/{slug}` | Debug route in production binary (main.go:556). |
| `GET /api/v1/kds/ws?token=` | JWT in URL; `CheckOrigin` returns true (ws/kds_ws_handler.go:83-86). |

## Attributes not individually enumerable from source

- **Validation**: no handler uses a validation library; `validate:"..."` struct tags (e.g. domain/order.go:107-136) are not processed (validator is only an indirect dependency in go.mod). Handlers hand-roll checks, hence `manual` in JSON.
- **Tenant scoping in SQL**: most repository queries include `tenant_id` (+`restaurant_id`); exceptions in BE-024. Not verified exhaustively for all query sites.
- **Test coverage**: name-based only. No HTTP-level test exercises `AuthMiddleware`+`TenantContextMiddleware`+RBAC end to end; `cmd/api/main_phase6_rbac_routes_test.go` only regex-matches main.go text. Tests were not run.
