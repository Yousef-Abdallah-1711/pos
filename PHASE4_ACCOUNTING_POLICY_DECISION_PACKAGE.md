# SERVIO Accounting and Product Policy Decisions

**Status:** DECISION REQUIRED — no recommendation below is approved or implemented.
**Audience:** Product owner, controller/qualified accountant, and the domain owner listed per decision.
**Financial boundary:** Keep the existing 5,000¢ Balance Sheet residual visible as `UNRECONCILED`; do not create a balancing journal or rewrite posted history.

This package consolidates the pending decisions used by Phase 4. The recommendations are proposals for owner discussion only. A decision should record the approved option, jurisdiction/effective date where applicable, approver names, and any implementation constraints before policy-dependent work begins.

Until that record exists, the proposed recommendations remain unapproved and policy-dependent implementation stays blocked.
